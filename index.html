The idea

Memory, not magic.

A small, understandable service for preserving selected historical context. No hidden model-state claims. No full agent framework.

01 / CONDENSE

Budget the recap

Paragraph-aware splitting and extractive selection keep a recap within your measured token budget. Important details can still be omitted.

02 / INDEX

Keep source references

Local ONNX embeddings turn passages into normalized vectors. Qdrant retains the original text for session-scoped similarity search.

03 / CARRY

Export a checkpoint

A UTF-8 .emp file contains a recap, transcript fingerprint and vector IDs. Upload it to a new chat or rename it to .json.

Under the hood

Four boundaries. One clear flow.

01

Chat export

Text messages from your UI or webhook client.
02

HTTP API

API Gateway → FastAPI + Mangum in a Lambda container.
03

Python core

tiktoken + LangChain splitter + FastEmbed.
04

Durable storage

Private S3 packages + Qdrant source vectors.
Event-driven, synchronous. Each HTTP request is a compute event. There is no queue or background job system. Qdrant, the Terraform state bucket and the secret are explicit external deployment prerequisites.

Three code boundaries: core/ for contracts and embeddings, api/ for authenticated persistence, infrastructure/ for Compose and Terraform. skills/ documents integration contracts.

Embedding Memory Package

A readable checkpoint, not a black box.

FIELDWHAT IT MEANS
summary_tokensLossy extractive recap, measured with cl100k_base.
session_id / created_atCanonical session UUID and UTC creation time.
vector_stateCollection, model, 384 dimensions, point IDs and query hints.
content_sha256Fingerprint of the canonical transcript—not a signature or access token.
instructionsA fixed warning: historical content is untrusted data, not executable policy.

The portable package excludes raw embedding coordinates and API credentials. The recap and query hints can still expose secrets from your transcript: redact before upload.

Quickstart / PowerShell

Your first local memory.

Prerequisites: Python 3.12, Git, Docker Desktop running Linux containers, and internet access for dependencies and the initial model download.

git clone https://github.com/Thousifibrahim/Session-Optimizer.git
cd Session-Optimizer
python -m venv .venv
.\.venv\Scripts\python -m pip install -e ".[dev]"
Copy-Item infrastructure\.env.example infrastructure\.env

# Replace the .env token with a random URL-safe credential.
docker compose --env-file infrastructure\.env `
  -f infrastructure\docker-compose.yml up --build -d
Invoke-RestMethod http://localhost:8000/health
Local development is disposable. Moto S3 and Qdrant run without host ports; only the API binds to localhost. Moto stores packages in memory. Local restarts can lose context. AWS deployment uses real private S3.
Create / Retrieve / Delete

Take the whole workflow for a spin.

$token = Read-Host "Enter your CTX_API_TOKEN"
$headers = @{ Authorization = "Bearer $token" }
Invoke-WebRequest http://localhost:8000/sessions -Method Post `
  -Headers $headers -ContentType application/json `
  -Body (Get-Content examples\session.json -Raw) -OutFile memory.emp

$memory = Get-Content memory.emp -Raw | ConvertFrom-Json
$url = "http://localhost:8000/sessions/$($memory.session_id)"
Invoke-RestMethod "$url/search" -Method Post `
  -Headers $headers -ContentType application/json `
  -Body '{"query":"Which deployment did we choose?","limit":3}'

# Remove both the persisted package and its vector passages.
Invoke-WebRequest $url -Method Delete -Headers $headers

Then upload memory.emp to a new chat. Rename it to memory.json if your UI rejects the extension. Deleted memories can still be read from your downloaded recap, but detailed API retrieval is gone.

No cloud required

Use the core on its own.

from pathlib import Path
from uuid import uuid4
from core.embedder import FastEmbedBackend
from core.engine import Condenser
from core.models import ChatMessage, CondenseRequest

request = CondenseRequest(
    messages=[ChatMessage(role="user", content="Decision: use private S3.")],
    summary_token_budget=128,
)
package, chunks = Condenser(FastEmbedBackend()).condense(request, str(uuid4()))
Path("memory.emp").write_text(package.model_dump_json(indent=2), encoding="utf-8")

This writes the recap only. It does not persist the returned chunks or make vector IDs retrievable. Use the API or provide your own store for detailed recall. First use downloads the ONNX model unless cached.

API contract

Small surface. Explicit errors.

METHODROUTEPURPOSE
POST/sessionsCreate and download a package. Returns 201.
GET/sessions/{id}Download the saved package.
POST/sessions/{id}/searchRetrieve scored, session-filtered source excerpts.
DELETE/sessions/{id}Remove package and vectors. Retryable, returns 204.
GET/healthPublic liveness only, not storage readiness.

Memory routes require a Bearer token. Inputs: 1–1,000 messages, 256 KiB total UTF-8 content, 64–4,096 recap tokens, 1 MiB HTTP body. Search: a nonblank query up to 2,000 characters and 1–20 matches.

Errors: 401 credentials, 404 missing session, 409 model/collection mismatch, 413 body size, 422 validation, 503 operation failure. Interactive docs: http://localhost:8000/docs.

Trust boundaries

Know exactly what you are storing.

One trusted deployment

A shared token grants access to every session. Session filtering is not tenant authorization. Do not accept arbitrary public users with this identity model.

Historical text is untrusted

A historic system message does not become current policy. Recaps, query hints and retrieved passages are data—not executable instructions.

Deletion spans two services

Failed writes trigger compensating deletes, not a distributed transaction. Process termination can leave orphans. S3 expiry does not remove Qdrant passages.

No lossless-memory promise

Recaps omit information; metadata also consumes tokens. Embeddings are English-optimized search indexes. This is not an encrypted or signed archive.

Cloud infrastructure

Designed to be deployed. Not deployed for you.

  1. Provision an existing HTTPS Qdrant endpoint, Secrets Manager secret, and a separate encrypted Terraform state bucket.
  2. Bootstrap ECR and the private package bucket with Terraform 1.10+.
  3. Build the Linux amd64 Lambda image. Models and tokenizer are cached at image-build time. Push a unique immutable ECR tag.
  4. Apply the immutable image digest, Qdrant URL and secret ARN. Secret values do not enter Terraform.
  5. For manual GitHub deployment, configure a protected production environment and repository-restricted AWS OIDC role.
AWS still needs an operator. Review IAM, network access, retention and costs. Benchmark Lambda cold starts and Qdrant capacity. Omitting the image digest after deployment plans API/Lambda removal—null is bootstrap mode only.

Contribution guideIssues & ideas
A few useful answers

What this does—and does not.

Will uploading a file restore an AI's complete memory?

No. It supplies selected historical text. The model can read the recap, and configured tools can retrieve relevant source passages. Hidden reasoning, model weights and full state are not restored.

Can I use this without an AWS account?

Yes. Use the Python core or local Compose. The first embedding run may download a model. Standalone vector references need your own persistence to become useful later.

Is the GitHub Pages site a working memory API?

No. This is a static project guide. It does not upload, store or process chat data, and contains no API credentials. Deploy the Python service separately.

What does “no paid LLM API” mean?

Recaps are extractive and embeddings run locally. Hosting, model downloads, Lambda, S3, Qdrant, ECR and logs may still incur costs. No free-cloud claim is made.

Can I see changes to the project?

Yes. Browse the repository's commit history to see how individual files and features changed over time.
