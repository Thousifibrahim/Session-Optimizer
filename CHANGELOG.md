# Changelog

Changes are recorded by release. This project has not yet made a production
release.

## Unreleased

- Token-budgeted extractive `.emp` packages and FastEmbed/Qdrant retrieval.
- Authenticated FastAPI service, private S3 storage and AWS Lambda/Terraform
  reference deployment.
- Local Compose, workflow examples, release documentation and isolated scenario
  tests.

## Versioning

Before the first release, API and `.emp` compatibility guarantees are provisional.
Future releases should document package migrations, model/index compatibility and
data-retention consequences.
